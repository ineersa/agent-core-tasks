# Add a setup command for Hatfield-provided extensions

## Goal
## Goal
Add a command similar to the existing provider setup command that guides users through installing, enabling, and configuring extensions provided with Hatfield.

## Scope
- Focus on extensions provided with Hatfield, not a general third-party extension marketplace.
- Reuse the existing provider setup interaction patterns and extension installation, configuration, and enablement facilities.

## Acceptance criteria
- Users can select Hatfield-provided extensions through a guided command similar to provider setup.
- The command supports installing, enabling, and completing the required setup for selected extensions through existing project facilities.
- Document the agreed command and cover the supported setup flows with tests.
