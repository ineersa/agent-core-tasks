## Investigation and implementation direction

Measurement-first: trace the exact model-facing edit schema/tool description, agent/fork guidance, valid patch grammar, and error retry hints. Determine why models emit invalid prefixes before choosing mechanics. The expected smallest fix is clearer concise prompting/guidance and actionable retry feedback, but this task does not pre-authorize provider-specific hacks or broad parser permissiveness.

Preserve strict edit safety. Do not silently repair malformed patches, guess user intent, accept ambiguous matches, weaken stale-context detection, or add new settings/commands/storage fields. Keep stable `E_PATCH_*` categories unless a concrete compatibility requirement is approved.
